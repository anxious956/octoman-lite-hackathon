      Steps and AWS services

      Step on the pageAWS serviceWhat it does
      Order arrivesAPI Gateway + LambdaStarts the workflow. A repeat cannot run twice.
      Check the shelfDynamoDB transactionTakes units only if enough are left.
      Update all 4 storesStep Functions Parallel stateAll four stores at once (mock mode).
      Convert to dollarsLambda + ECB ratesToday's European Central Bank rate.
      Low-stock warningDynamoDBWarns below the warning level.
      Save receiptLambda + S3Stores a receipt, marks the order sold.

      Why it cannot oversell

      • One shelf number. No store keeps its own copy.
      • Checking and taking are one database step, so two orders cannot both get the last item.
      • An order that is too big is blocked. Nothing is sold.

      About this demo

      • Made-up products and orders.
      • Amazon requests are built but never sent (mock mode). No Amazon seller account is involved.
      • Costs nothing while nobody orders.
